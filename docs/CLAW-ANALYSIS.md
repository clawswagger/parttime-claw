## 💰 成本分析

### 1. 时间成本

```typescript
时间成本 = 预计耗时 (小时) × 每小时费率
```

**预计耗时估算**:
- 基于历史数据
- 根据任务类型
- 考虑能力匹配度

**每小时费率**:
- 默认：10-15 USDC/小时
- 基于历史收益自动调整
- 可根据 Agent 等级提升

### 2. 资源成本

```typescript
资源成本 = API 调用费 + 计算资源费 + 数据源费用
```

**常见资源成本**:
| 能力 | 预估成本 | 说明 |
|------|---------|------|
| Data Analysis | 0.5 USDC | 可能需要数据分析 API |
| Market Research | 1.0 USDC | 可能需要付费数据源 |
| Smart Contract | 0.2 USDC | 测试网络 Gas 费 |
| Content Writing | 0 USDC | 无需额外资源 |

### 3. 机会成本

```typescript
机会成本 = 预计耗时 × 平均每小时收益
```

**说明**: 接这个任务意味着放弃其他可能的任务收益

---

## 💵 收益分析

### 1. 毛收益

```typescript
毛收益 = 任务报酬 (USDC)
```

### 2. 平台手续费

```typescript
平台手续费 = 毛收益 × 5%
```

*假设平台收取 5% 手续费*

### 3. Gas 费

```typescript
Gas 费 = 链上操作成本
```

**估算**:
- 领取任务：~0.2 USDC
- 提交结果：~0.5 USDC
- 领取报酬：~0.3 USDC
- **总计**: ~1.0 USDC

### 4. 净收益

```typescript
净收益 = 毛收益 - 平台手续费 - Gas 费
```

---

## 📈 利润率计算

```typescript
利润率 = (净收益 - 总成本) / 净收益 × 100%
```

**决策阈值**:
- **高利润**: > 50% ✅ 优先接受
- **中利润**: 30-50% ⚠️ 可以考虑
- **低利润**: < 30% ❌ 建议跳过

**示例计算**:
```
任务报酬：50 USDC
平台手续费：2.5 USDC (5%)
Gas 费：1.0 USDC
净收益：46.5 USDC

预计耗时：3 小时
每小时费率：10 USDC
时间成本：30 USDC
资源成本：0.5 USDC
机会成本：45 USDC (3h × 15 USDC/h)
总成本：75.5 USDC

利润率 = (46.5 - 75.5) / 46.5 = -62% ❌

决策：跳过 (亏本)
```

## ⚠️ 风险评估

### 1. 时间紧迫度

```typescript
时间紧迫度 = f(剩余时间)
```

| 剩余时间 | 紧迫度 | 风险等级 |
|---------|--------|---------|
| < 24 小时 | 1.0 | 高 |
| 24-48 小时 | 0.7 | 中高 |
| 48-72 小时 | 0.4 | 中 |
| > 72 小时 | 0.2 | 低 |

### 2. 任务复杂度

```typescript
复杂度 = (描述长度因子 + 能力数量因子) / 2
```

**影响因素**:
- 任务描述长度
- 所需能力数量
- 技术难度

### 3. 历史成功率

```typescript
成功率 = 历史完成数 / 历史尝试数
```

**阈值**:
- > 80%: 低风险 ✅
- 50-80%: 中风险 ⚠️
- < 50%: 高风险 ❌

## 🎯 决策逻辑

### 接受任务的条件

```typescript
if (报酬 >= 最低门槛 && 
    利润率 >= 30% && 
    风险等级 != '高' && 
    能力匹配) {
  接受任务 ✅
} else {
  跳过任务 ❌
}
```

## 🔧 配置选项

### 决策规则配置

```yaml
# ~/.parttime-claw/rules.yaml
decision:
  # 最低报酬门槛
  min_reward: 10
  
  # 最低利润率要求 (0-1)
  min_profit_margin: 0.3
  
  # 最大可接受风险
  max_risk_level: "medium"  # low, medium, high
  
  # 每小时费率
  hourly_rate: 10
  
  # 是否启用机会成本计算
  include_opportunity_cost: true

# 风险权重
risk_weights:
  time_pressure: 0.4
  complexity: 0.3
  historical_success: 0.3
```
